# calculadora-perimetros Angular + Ionic

Este proyecto fue desarrollado como parte del Taller N°1 de la Unidad I en la asignatura de Programación Híbrida. La aplicación permite calcular el perímetro de figuras geométricas como el círculo y el triángulo, utilizando componentes standalone en Angular e Ionic.

## 🛠️ Tecnologías utilizadas

- Angular + Ionic
- TypeScript
- SCSS
- Visual Studio Code + WebNative

## 📦 Estructura del proyecto

- `src/app/circulo`: componente para calcular el perímetro de un círculo.
- `src/app/triangulo`: componente para calcular el perímetro de un triángulo.
- `src/app/modelo`: clases TypeScript que representan figuras geométricas.
- `src/app/home`: página principal con selector dinámico.
